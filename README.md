# CS50

Working through two Harvard CS50 courses as part of rebuilding hands-on coding 
fundamentals alongside my AI/ML portfolio projects.

This sits alongside my portfolio projects — the goal is to close gaps in core CS 
fundamentals that don't always surface in day-to-day AI/ML work.

---

## CS50x — Introduction to Computer Science

[cs50.harvard.edu/x](https://cs50.harvard.edu/x/)

Covers computer science fundamentals from scratch: C, algorithms, memory, data 
structures, Python, SQL, and web development. Starts with C to understand what's 
happening under the hood, then moves up the stack.

## CS50P — Introduction to Programming with Python

[cs50.harvard.edu/python](https://cs50.harvard.edu/python/)

Entirely focused on Python programming. Covers functions, exceptions, unit tests, 
file I/O, regular expressions, OOP, and libraries. Can be taken alongside CS50x 
or independently.
